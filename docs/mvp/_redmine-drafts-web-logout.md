## Тема

**[#37519](http://support.luxsoft.by/issues/37519) [Веб] Нет выхода из веб-клиента
под пользователем без роли администратора** — оценка S.

## Локации и факты разбора

- Кнопка «Выход» — платформенная: системный `Authentication` создаёт папку «Учётная запись»
  c `logOutAction = restart[]` в `WINDOW toolbar` (распакованный системный модуль
  `logs/jarx/system/Authentication.lsf:991-995`). В веб-клиенте папка создаётся всегда:
  отключающий флаг `noSystemToolbarCaptions() += isNativeDesktop()` (только desktop).
- Видимость: `permit[User, NavigatorElement]` — разрешено, если хоть одна роль permit
  или ни одна не forbid; роль `readonly` вдобавок прячет действия (связка view/change).
  Значит у рабочей учётки кнопку прячет Forbid в политике её роли (или запрет на папку).
- Своих политик в проекте нет (`src/main/lsfusion` не трогает security policy/тулбар) —
  вопрос конфигурации стенда. Проверить под zav216 (erp-стенд) и учёткой без ролей
  (standalone 9080). На момент разбора оба стенда не подняты.
- Кодовое решение: свой пункт навигатора `NEW ACTION … = restart[]` в `StoreTaskStandalone`
  (или метах) — виден всем, кому разрешён навигатор задач, независимо от системной папки.
